Krypto-Steuer-Akademie – Mehrseiten-Version V1
================================================

UPLOAD NACH GITHUB
1. Den kompletten Inhalt dieses Ordners in einen neuen GitHub-Ordner hochladen,
   zum Beispiel:
   pages/krypto-steuer-akademie/

2. Die Ordnerstruktur muss erhalten bleiben:
   - index.html
   - weitere HTML-Seiten
   - assets/css/app.css
   - assets/js/store.js
   - assets/js/csv.js
   - assets/js/app.js
   - archiv/krypto-steuer-assistent-bisheriger-stand.html

3. Startadresse:
   /pages/krypto-steuer-akademie/index.html

WICHTIG
- Alle Seiten teilen dieselbe Datenbasis über localStorage.
- Ein Steuerjahr kann oben auf jeder Seite gewechselt werden.
- Das vollständige Projekt kann als JSON gesichert und wieder geladen werden.
- Die bisherige Einseiten-Version liegt unverändert im Ordner "archiv".
- Keine Private Keys oder Seed Phrases eingeben.

ERSTER TEST
1. Projektakte anlegen.
2. Anbieter erfassen.
3. BSC-Wallet erfassen.
4. Wallet-Auswertung öffnen.
5. echte BscScan Token-Transfer-CSV einlesen.
6. Transaktionsseite öffnen und gebildete Vorgänge prüfen.
7. Prüffälle aktualisieren.
8. Übergabeakte öffnen.
