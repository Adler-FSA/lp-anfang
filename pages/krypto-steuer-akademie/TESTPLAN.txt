TESTPLAN – ERSTE ABNAHME

A. Navigation und gemeinsame Daten
[ ] Alle Seiten öffnen ohne 404.
[ ] Steuerjahr bleibt beim Seitenwechsel erhalten.
[ ] Anbieter und Wallet erscheinen auf allen passenden Seiten.
[ ] Backup herunterladen und wieder einlesen.

B. Wallet-Import
[ ] BscScan Token-Transfer-CSV wird erkannt.
[ ] Spalten "Transaction Hash", "DateTime (UTC)", "From", "To", "Amount", "Token" werden verarbeitet.
[ ] Erneuter Import derselben erfolgreichen Datei wird blockiert.
[ ] Eine frühere Datei mit 0 übernommenen Zeilen darf erneut verarbeitet werden.
[ ] Bewegungen erscheinen im Wallet-Arbeitsbereich.
[ ] Gleiche Hashes werden zu wirtschaftlichen Vorgängen zusammengeführt.

C. Transaktionen
[ ] Vorgänge erscheinen in der zentralen Transaktionsliste.
[ ] Suche funktioniert.
[ ] Filter "offene Prüffälle" funktioniert.
[ ] Verdächtige Token werden markiert.
[ ] Manuelle Ergänzung wird gespeichert.

D. Nachweise und Prüfung
[ ] Bankbewegung wird gespeichert.
[ ] Nachweis mit Dateiname und Zuordnung wird dokumentiert.
[ ] Automatische Prüfung erzeugt Hinweise bei fehlenden Wallet- oder Börsendaten.
[ ] Prüffälle können erledigt und wieder geöffnet werden.

E. Übergabe
[ ] Zusammenfassung zählt alle Bereiche richtig.
[ ] CSV-Export der Vorgänge funktioniert.
[ ] Druckansicht/PDF funktioniert.
